# Related Work And Contribution Boundary

Public-registry research was repeated before development: 3,543 module names,
21,510 version records, 30 related published archives with matching SHA-256,
and 20 related GitHub source repositories. No JCAMP-specific MoonBit entry
point was identified in that bounded search. This is not a guarantee of
worldwide uniqueness, exhaustive GitHub indexing, or competition approval.

Relevant existing MoonBit projects include:

- https://github.com/chgttyyr/MoonSpectrum : FFT, filters and scientific signals.
- https://github.com/zc222er/moonbit-thinfilm-tmm : thin-film optics and inversion.
- https://github.com/shangwuxi/moondiffraction : reciprocal diffraction.
- https://github.com/cn-wn/MoonSignalKit : streaming telemetry statistics.
- https://github.com/paipai-Studio/BioSeqs : biological sequences and structures.

MoonJCAMP's intended contribution is JCAMP-DX record/table semantics,
compressed numeric interchange, compound data and independently checked
rewriting. Shared numerical methods, text parsers, CSV/JSON, diagnostics,
tests and packaging are engineering necessities, not exclusive inventions.

Other languages already implement JCAMP-DX. The project is a new MoonBit
implementation of an existing standard, not a new scientific format or a
claim that the problem has never been solved.
